1. Descripción general

TRU (Truck Center) gestiona el control de acceso, registro y seguimiento de camiones en el parking del Truck Center de la APB. Integra lecturas automáticas de matrículas (LPR) de cámaras IKUSI con un panel web de gestión de entradas, salidas, asignación a terminales, conductores y empresas de transporte.

1.5 Máquina de estados (fases del expediente)

    ┌──────────────────┐
    ▼                  │  Creación vía LPR (API) o manual (Web)
┌───────────────┐      │
│ EN EL PARKING │──────┘
└──────┬────────┘
       │  Transiciones:
       │   1. Botón "Salir del Parking" (Web) → HORA_SORTIDA = now
       │   2. Lectura LPR salida (acceso=24, carril=91)
       │   3. Alta duplicado confirmado → cierra anterior (HORA_SORTIDA = now − 1s)
       ▼
┌────────────────┐
│ FORA DEL PARKING│  ← Estado final
└────────────────┘

Regla de duplicados (crítica): al crear (manual o API) con matrícula ya presente sin HORA_SORTIDA: - Vía Web: aviso y confirmación → si confirma, cierra anterior (HORA_SORTIDA = now − 1s, FASE = FORA DEL PARKING) y crea nuevo; si cancela, no permite alta. - Vía API/LPR: cierra anterior y crea nuevo automáticamente, sin confirmación del usuario.

2.1 API ControlPuertas (APB.API.LGP)

POST /api/v1/TruckCenter/ControlPuertas — Permiso requerido: API_CALL_TRU_CONTROL_PUERTAS

Parámetros de entrada:

Campo Uso Descripción
acceso ✅ Validado Puerta del puerto (determina entrada/salida)
carril ✅ Validado Calle de circulación (determina entrada/salida)
fecha ✅ Validado Hora de llegada/salida
lecturasMatricula.matricula ✅ Validado Matrícula del camión
idCamara ❌ Ignorado Cambió de Integer (8 díg.) a Long (17 díg.) — TRANSTE-1522
Resto de campos ❌ Ignorado No se validan ni procesan (TRANSTE-1523)

Lógica de negocio — determinación entrada/salida: acceso=24 AND carril=90 → ENTRADA · acceso=24 AND carril=91 → SALIDA.

  • Flujo ENTRADA: (1) buscar en TRUCK_CENTER registro con misma matrícula sin HORA_SORTIDA; (2) si

existe → cerrar anterior (HORA_SORTIDA = now − 1s, FASE = FORA DEL PARKING); (3) crear nuevo (HORA_ENTRADA = fecha_param, MATRICULA_CAMIO = matricula_param, FASE = EN EL PARKING, CONEXIO_ELECTRICITAT = 0, ITV = 0). - Flujo SALIDA: (1) buscar registro activo con misma matrícula; (2) si existe → HORA_SORTIDA = fecha_param, FASE = FORA DEL PARKING. - Matrícula ausente (TRANSTE-1513): cuando la cámara no detecta matrícula → evento TRU_CONTROL_PUERTAS_KO con texto Control de Acceso OK:Número tarjeta:/Acceso:24/Carril:90/Fecha:29/4/2024 13:14:56/Matricula:NOMATRI. - Campo idCamara (TRANSTE-1522): cambio de formato 8 (Integer) → 17 (Long) números; aunque no se usa en lógica de negocio, el JSON lo incluye y se ajustó para que el cambio de tamaño no provoque error de parsing.
